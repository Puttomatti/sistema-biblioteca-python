# Sistema de Biblioteca em Python

Projeto desenvolvido durante meus estudos de Python para colocar em prática conceitos de Programação Orientada a Objetos.

O sistema simula o gerenciamento básico de uma biblioteca, utilizando as classes `Livro` e `Biblioteca` para organizar as funcionalidades.

## Funcionalidades

* Cadastro de livros
* Empréstimo de livros
* Devolução de livros
* Gerenciamento dos livros por meio das classes do sistema

## Conceitos aplicados

* Python
* Programação Orientada a Objetos (POO)
* Classes e objetos
* Métodos
* Lógica de programação

## Como executar

Com o Python instalado, execute:

```bash
python sistema_biblioteca.py
```
